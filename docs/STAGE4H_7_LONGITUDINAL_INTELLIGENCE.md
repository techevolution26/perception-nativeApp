# Stage 4H.7 — Longitudinal Intelligence (Mobile)

Adds the Profile Intelligence surface that reads `/api/analytics/profile` and presents longitudinal evidence across the authenticated user's authored Perceptions and Topics.

The existing **Analytical profile** screen remains configuration (professional/topic/geographic analytics context). It is not replaced by Profile Intelligence.

The intelligence surface uses:

- 180-day default window
- 30-day buckets
- minimum 5 analyzed comments
- qualifying Topic summaries
- recurring themes across Topics
- observed temporal patterns
- explicit methodological limitations

No participant identities are displayed.
